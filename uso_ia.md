## 5. Ajustes realizados

Durante el desarrollo fue necesario realizar diferentes modificaciones.

**Corrección de Header y Footer:** Se identificó que estaba utilizando etiquetas con mayúsculas dentro de componentes con los mismos nombres. Se corrigieron utilizando las etiquetas HTML `<header>` y `<footer>`.

**Corrección de navegación:** Se modificó la ruta de Inicio para utilizar `/` en lugar de `/inicio`, de acuerdo con la configuración de React Router.

**Personalización del contenido:** Se incorporó información relacionada con mis estudios, intereses y proyectos personales.

**Selección de proyectos:** Se decidió incluir únicamente dos proyectos: EID, desarrollado con Python y Pygame, y mi Portafolio Web.

**Adaptación del diseño:** Se realizaron modificaciones en las tarjetas, los estilos y las barras de habilidades para aproximar el resultado al wireframe entregado por el profesor.

## 6. Reflexión crítica

Utilizar ChatGPT me permitió comprender mejor cómo se organiza una aplicación React y cómo se relacionan sus diferentes componentes.

Una de mis principales dificultades fue solucionar los errores que provocaban que la pantalla apareciera completamente blanca. Al revisar el código, comprendí mejor la diferencia entre los componentes React y las etiquetas HTML.

También pude aprender sobre la navegación con React Router, el uso de props, el manejo de estados con `useState` y la generación de elementos mediante `.map()`.

La inteligencia artificial me ayudó proporcionando ejemplos y explicaciones, pero también fue necesario probar el código, detectar problemas y solicitar correcciones cuando los resultados no cumplían con lo esperado.

Considero que fue una herramienta útil para apoyar mi aprendizaje, aunque es importante comprender el funcionamiento del código y no limitarse a copiarlo.
